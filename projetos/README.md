# projetos

Projetos leves e autocontidos — apresentações, documentos e artefatos que não vão para deploy no Vercel e não justificam repositório próprio.

## Convenção

Uma pasta por projeto, com o arquivo principal como `index.html`. Basta abrir no navegador; não há build nem dependência.

```
projetos/
  <nome-do-projeto>/
    index.html
```

Versionamento é por histórico de commit. Não crie `index_v2.html`, `index_final.html` ou equivalentes.
